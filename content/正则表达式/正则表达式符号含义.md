# 二、符号含义
## 基础符号匹配

| 符号   | 含义                            | 示例                      |
| ---- | ----------------------------- | ----------------------- |
| `.`  | 匹配除换行符以外的任意单个字符               | `a.b` → 匹配 `acb`, `a9b` |
| `\d` | 数字字符（0–9）                     | `\d\d` → 两位数字           |
| `\D` | 非数字字符                         | `\D+` → 连续的非数字          |
| `\w` | 字母、数字、下划线（等价于 `[A-Za-z0-9_]`） | `\w+` → 一个单词            |
| `\W` | 非字母数字下划线                      | `\W+` → 特殊符号            |
| `\s` | 空白字符（空格、制表符、换行）               | `\s+` → 空格或制表符          |
| `\S` | 非空白字符                         | `\S+` → 非空字符序列          |
| `\n` | 换行符                           |                         |
| `\r` | 回车符                           |                         |
| `\t` | 制表符                           |                         |
| `\\` | 转义反斜杠本身                       |                         |

## 数量限定符（量词）

| 符号      | 含义             | 示例                             |
| ------- | -------------- | ------------------------------ |
| `*`     | 重复 0 次或多次      | `ab*` → `a`, `ab`, `abbb`      |
| `+`     | 重复 1 次或多次      | `ab+` → `ab`, `abbbb`          |
| `?`     | 出现 0 或 1 次（可选） | `colou?r` → `color`, `colour`  |
| `{n}`   | 恰好 n 次         | `a{3}` → `aaa`                 |
| `{n,}`  | 至少 n 次         | `a{2,}` → `aa`, `aaaa`         |
| `{n,m}` | n 到 m 次之间      | `a{2,4}` → `aa`, `aaa`, `aaaa` |

## 字符类

| 符号             | 含义                   | 示例                      |
| -------------- | -------------------- | ----------------------- |
| `[abc]`        | 匹配 `a` 或 `b` 或 `c`   | `[ch]at` → `cat`, `hat` |
| `[^abc]`       | 匹配除 `a,b,c` 外的任意字符   | `[^0-9]` → 非数字          |
| `[a-z]`        | 小写字母范围               |                         |
| `[A-Z]`        | 大写字母范围               |                         |
| `[0-9]`        | 数字范围                 |                         |
| `[a-zA-Z0-9_]` | 通用单词字符（等价 `\w`）      |                         |
| `[-]`          | 匹配字面量连字符（要放开头或转义）    |                         |
| `[\]]`         | 匹配 `]` 字符本身（或用 `\]`） |                         |

## 位置锚点（Anchors）

| 符号   | 含义                    | 示例                      |
| ---- | --------------------- | ----------------------- |
| `^`  | 行首                    | `^abc` → 行首为 `abc`      |
| `$`  | 行尾                    | `xyz$` → 行尾为 `xyz`      |
| `\b` | 单词边界（word boundary）   | `\bcat\b` → 匹配独立的 `cat` |
| `\B` | 非单词边界                 | `\Bcat` → 例如 `educate`  |
| `\A` | 匹配字符串开始（不受多行模式影响）     |                         |
| `\Z` | 匹配字符串结束（不受多行模式影响）     |                         |
| `\z` | 严格匹配字符串结束（比 `\Z` 更严格） |                         |

## 分组与引用

| 符号             | 含义                 | 示例                            |
| -------------- | ------------------ | ----------------------------- |
| `(abc)`        | 捕获组（记住匹配的内容）       | `(ab)+` 匹配并捕获多次               |
| `(?:abc)`      | 非捕获组               | 不保存匹配内容，只用于分组逻辑               |
| `(?<name>abc)` | 命名捕获组（Python/PCRE） | `(?<word>\w+)`                |
| `\1`, `\2`...  | 引用第 1、2... 个捕获组    | `(.)\1` → 匹配重复字符，如 `aa`, `bb` |
| `(?P=name)`    | Python 中引用命名组      | `(?P<word>\w+) \1`            |

# 三、惰性匹配

**懒惰匹配（Lazy Matching）** 是正则表达式里一个非常关键的概念，它和默认的 **贪婪匹配（Greedy Matching）** 是一对相反的行为。

## 基础概念对比

|类型|英文名|符号|行为|
|---|---|---|---|
|贪婪匹配|Greedy|`*`, `+`, `{m,n}`|**尽可能多地匹配**|
|懒惰匹配|Lazy|`*?`, `+?`, `{m,n}?`|**尽可能少地匹配**（在能满足整个表达式的前提下）|
正则在匹配时会**从左到右扫描字符串**。  
当遇到像 `.*` 这种可以重复的量词时：
- **贪婪模式**：先尽量多吃字符，  
    如果后续匹配失败，再一点点回退（**回溯**）。
- **懒惰模式**：先尽量少吃字符，  
    如果后续匹配失败，再一点点往后吃。

---

## 举例

```
abc123xyz456xyz
```

### 贪婪匹配：`a.*x`

- `.*` 会尽可能多地匹配
- 结果匹配：`abc123xyz456x`  
    因为它一直吃到最后一个 `x` 才停

### 懒惰匹配：`a.*?x`

- `.*?` 会尽可能少地匹配
- 结果匹配：`abc123x`  
    因为它只要碰到第一个 `x` 就停下来了
